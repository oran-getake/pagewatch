## 30文字程度の短い説明

Webページの文章差分を扱うSwiftUI＋FastAPIの学習用ソースです。

## 掲載用本文

登録した公開Webページを定期確認し、前回から変わった文章をiPhone画面に表示する「PageWatch」の学習用ソースコードです。

FastAPI API、PostgreSQL対応のデータモデル、データベース式ジョブキュー、Worker、Cron、SwiftUI iPhoneアプリを一つのリポジトリで読めます。匿名端末トークン、Keychain保存、SSRF対策、robots.txt確認、本文抽出、追加・削除差分など、Web監視アプリの構成を学びたい方向けです。

### 含まれるもの

- FastAPI API
- SQLAlchemyモデルとAlembicマイグレーション
- SQLiteでのローカル起動構成
- PostgreSQLを使うRailway向け構成
- データベース式ジョブキュー、Worker、Cron
- 公開URLの安全確認、robots.txt確認、本文抽出、文章差分
- SwiftUI iPhoneアプリ
- 実装手順、配置図、詳細設計、テスト仕様
- 利用ガイド、FAQ、商用利用条件

### 実装済みの主な内容

- 匿名端末トークン発行とKeychain保存
- 1端末5件までのURL登録
- 一覧、詳細、一時停止、再開、削除
- 匿名端末データの一括削除
- 登録直後、手動、定期確認
- 5分の手動確認間隔
- 文章抽出、スナップショット、追加・削除差分
- 内部IP、認証情報付きURL、非標準ポートの拒否
- 取得サイズ、本文サイズ、リダイレクト回数、タイムアウト制限
- 停止したWorkerが残したジョブの回収

### 重要：完成アプリではありません

- 本配布物は学習・検証・改造用のソースコードです。App Store公開済みアプリや運営中サービスではありません。
- 実機およびTestFlightでの最終確認は未完了です。
- RailwayへのAPI、Worker、Cron、PostgreSQLの配置は購入者／利用者自身で行います。
- Release用API URL、Apple Developer署名、Bundle ID等の設定が必要です。
- プライバシーポリシー等は正式URLへ置き換える必要があります。
- 対象サイトごとの利用規約、robots.txt、権利、アクセス負荷、法令を利用者自身で確認してください。
- サイト構造、JavaScript描画、Bot対策等により取得できないページがあります。
- 個別の設置、質問対応、改修、公開審査対応は含まれません。

### こんな方に向いています

- SwiftUIアプリとPython APIのつなぎ方を読みたい
- 匿名端末認証やKeychain保存の実装例を見たい
- Railway上でAPI、Worker、Cron、PostgreSQLを分ける構成を学びたい
- Webページ取得時のSSRF対策や負荷制限を学びたい
- 自分で検証・改造しながら完成へ近づけたい
